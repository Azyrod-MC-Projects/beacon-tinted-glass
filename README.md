# Beacon Tinted Glass

This mod allows you to hide all theses ugly beacon beams around your base without getting rid of the effects !  
When adding a tinted glass above a beacon beam, the beam will stop at that Tinted Glass block and be completely invisible above. You can still color the beam as you want before the Tinted Glass block, and you also have control over how/if you can color the beam above the Tinted Glass :

## Tinted Glass Modes

![Showing off all 3 modes available to the mod. Allows you to tailor it to your expectations.](https://cdn.modrinth.com/data/mYqUO7Hx/images/7f4542686c6685f9edb1f91ac9745c04f85cc64c.png)

There is 3 modes of the mod to determine what happens if you try to color the beam after a tinted glass block :
- Block Once: Tinted Glass will block the beam once, and will allow a normal Colored Glass block to restore the beam if placed above the tinted glass.
- Toggle: Tinted Glass will block the beam until the next Tinted Glass block, ignoring every Colored Glass in between
- Block Forever: Tinted Glass will block the beam and not let anything turn it back on
